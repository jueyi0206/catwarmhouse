# 日日暖暖中途貓窩 官方網站

高雄中途貓窩「日日暖暖中途貓窩」的官方網站。
由志工瑞億協助製作，內容以貓窩官方公告為準。

> ⚠️ **目前是雛形，尚未對外公開。**
> 網頁上所有紅色框框都是待貓窩確認的段落，上線前要全部處理掉。

---

## 怎麼預覽

**最簡單**：直接用 Chrome 或 Edge 打開 `index.html`，不用裝任何東西。

**完整預覽**（含分享預覽圖等功能）：在這個資料夾開終端機執行，然後開 http://localhost:8099

```bash
python -m http.server 8099
```

---

## 平常要改什麼

網站的內容集中在 `data/` 資料夾，**改那裡就好，不用碰 HTML**：

| 檔案 | 內容 |
|---|---|
| `data/cats.js` | 貓咪資料（照片、個性、健康狀況、YouTube 影片） |
| `data/news.js` | 最新消息 |
| `data/tips.js` | 養貓小知識文章 |
| `data/shop.js` | 義賣商品 |
| `data/games.js` | 小遊戲 |

操作方法寫在 **`data/貓咪資料怎麼改.md`**（五個檔的改法都一樣）。

照片放在 `images/`，放之前請看該資料夾裡的注意事項（人臉、醫療照的規矩）。

## 技術說明

純 HTML + CSS + JavaScript，沒有框架、沒有資料庫、不用編譯。
這樣的網站免費、快速，而且放著十年都不會壞。

- `assets/style.css` — 全站樣式，**配色集中在檔案最上面那一段**
- `assets/site.js` — 共用程式（選單、資料渲染、影片播放器）

### 改完 assets/ 或 data/ 要跑這個

瀏覽器會把 CSS 和 JS 暫存 10 分鐘，不處理的話使用者可能拿到
「新的網頁 ＋ 舊的程式」，畫面會壞掉。推上 GitHub 之前跑一次：

```bash
python tools/更新版本號.py
```

它會在網頁引用檔案的網址後面加上內容版本號，內容一變瀏覽器就會重新抓。
跑完還會順便檢查字型有沒有缺字，有缺才需要處理（見下一段）。

### 關於中文圓體

網站用的是「jf open 粉圓體」（justfont 開源，SIL OFL 授權，可免費商用）。
原檔 4.7 MB，為了手機載入速度，只收了網站用到的字，精簡成約 200 KB。

**平常不用管它。** 加了新文字之後，跑 `更新版本號.py` 時會自動檢查，
真的有字沒收到才會提醒你跑：

```bash
python tools/產生字型.py
```

沒跑也不會壞 —— 沒收錄的字會用電腦內建的字型顯示，只是看起來跟其他字不一樣。

影片採「點一下才載入」，頁面載入時不會連到 YouTube，
訪客按了播放才載入，且走 `youtube-nocookie` 網域。

## 製作進度

**`progress.html`** 是給貓窩夥伴看的進度頁 —— 哪些做完了、哪些在等誰回覆，
用瀏覽器打開就能看，每一項都連到對應的頁面。網站頂端的橫幅也有連結。
