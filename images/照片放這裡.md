# 照片放這裡

貓咪照片放在這個資料夾，然後在 `data/cats.js` 的 `photo` 欄位填檔名。

## 檔名規則
- 用英文小寫，例：`cream.jpg`、`chienchien.jpg`
- 不要用中文檔名，有些主機會出問題
- 建議跟該隻貓的 `id` 同名，好對照

## 放之前一定要檢查（貓窩規則）
- [ ] 有沒有人臉入鏡？沒確認當事人同意前一律不用
- [ ] 是不是醫療照？傷口、手術、生病的照片不放
- [ ] 貓咪看起來狀態好嗎？不賣慘
- [ ] 寬度縮到 1000 像素以內了嗎？不然手機開很慢

## 建議尺寸
- 卡片用的照片：寬 800～1000 像素，橫式（4:3）最好看
- 檔案大小控制在 300KB 以內

## LOGO 檔案說明

貓窩的 LOGO 已經放進來了，網站各處自動使用，**不用手動改**：

| 檔名 | 用途 |
|---|---|
| `logo.jpg` | 原始檔，貓窩提供的原圖，保留備份用 |
| `logo-round.png` | 大圖，已裁成圓形、去掉白底 |
| `logo-264.png` | 首頁主視覺 |
| `logo-160.png` | 備用 |
| `logo-72.png` | 每頁左上角 |
| `favicon.png` | 瀏覽器分頁的小圖示 |
| `logo-share.jpg` | 貼到 FB／LINE 時的預覽圖 |

⚠️ `logo-share.jpg` 要等網域確定後，把各頁 HTML 裡的 `og:image` 改成完整網址才會生效，
只寫相對路徑 FB 抓不到圖。

如果之後有新版 LOGO，把新檔存成 `logo.jpg` 蓋掉舊的，
再跟 Claude 說一聲重新產生各尺寸就好。

### 網站配色是從 LOGO 取出來的

整體走「藍白」調，配合 LOGO 的藍色圓章。

| 顏色 | 色碼 | 用在哪 |
|---|---|---|
| LOGO 的藍 | `#3459C3` | 按鈕、選單、流程步驟的圓圈 |
| 藍白底 | `#F6F9FD` | 頁面底色 |
| 淡藍 | `#E9F0FA` | 主視覺、區塊底色 |
| 純白 | `#FFFFFF` | 卡片 |
| 深藍灰 | `#26314A` | 文字、頁尾 |
| LOGO 的橘 | `#EF8C53` | 統計數字、價格等強調處（只用在小地方，讓畫面不會太冷） |

要調整的話改 `assets/style.css` 最上面那一段就好，全站會一起變。
