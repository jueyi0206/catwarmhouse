# 網站插畫風格指南

> 目的：讓網站上每一張插圖看起來都是同一位畫家畫的。
> 做法：每次請 AI 做圖，都**原封不動貼上第一節的「風格描述」**，再加上這張圖要畫什麼。
> 風格來源：《認養流程_設計稿_v3.jpg》，色碼是從那張圖實際取樣出來的。
> 2026-10-13 建立。

---

## 一、風格描述（每次都貼這一段，不要改）

```
【美術風格｜請嚴格遵守】
- 日系可愛風的手繪貓咪插畫，Q版比例：頭大、身體小、圓滾滾
- 輪廓線是深咖啡色（#4A1D0C），不是黑色；線條粗細一致、圓潤、
  帶一點手繪的不完美感
- 眼睛是又大又圓的深色眼珠，上面有白色反光點
- 臉頰有粉嫩的橢圓腮紅（#FCBAB0），嘴巴是小小的「ω」形
- 耳朵內側是淡粉色
- 上色是平塗色塊，幾乎沒有陰影，不要寫實質感、不要 3D、不要漸層光澤
- 貓咪種類以這兩種為主：
  ・橘白貓：橘色（#FAB160）加白色，身上有淡淡的橘色虎斑紋
  ・灰白虎斑貓：灰色（#999594）加白色，額頭與身上有深灰色條紋，
    口鼻與胸口是白色
- 點綴的小裝飾：粉紅愛心（#F47479）、黃色短線與小閃光（#FDC06B）、
  藍灰色的貓掌印（#8896B6）、圓角對話泡泡
- 整體色調柔和、明亮、溫暖，像繪本插畫
- 背景是非常淡的藍白色（#F2F7FD 到 #F5F8FD），乾淨不雜亂

【不要出現】
- 不要任何文字、字母、數字、標誌（文字會由網頁另外排上去）
- 不要寫實照片風格、不要水彩暈染、不要厚塗、不要 3D 渲染
- 不要黑色粗框、不要深色或暗沉的背景
- 不要出現人物
```

> 為什麼要「不要任何文字」：AI 寫中文很容易寫錯（之前「無虞」就被寫成「無慮」），
> 而且網頁上的標題用真的文字排，手機上才不會糊、Google 也搜得到。

## 二、網站配色（插圖要跟這些搭）

| 用途 | 色碼 |
|---|---|
| 網站主色（按鈕、選單） | `#3459C3` 藍 |
| 頁面底色 | `#F6F9FD` 藍白 |
| 區塊底色 | `#E9F0FA` 淡藍 |
| 強調色（數字、價格） | `#EF8C53` 橘 |
| 文字 | `#26314A` 深藍灰 |

插圖的底色跟網站底色幾乎一樣（設計稿 `#F2F7FD`、網站 `#F6F9FD`），
所以插圖放上網站時邊緣會自然融進去，不會有一塊色差。

## 三、「等家的貓咪」頁的背景

### 先決定放哪裡：建議做「頁首橫幅」，不要做「整頁背景」

| | 頁首橫幅（建議） | 整頁背景 |
|---|---|---|
| 位置 | 頁面最上方，標題「等家的貓咪」放在上面 | 鋪滿整頁，貓咪卡片疊在上面 |
| 優點 | 第一眼就有氛圍；不干擾下面的貓咪卡片 | 整頁都有風格 |
| 缺點 | 只有上方有插畫 | **會跟真的貓咪照片搶注意力**；卡片上的字變難讀；手機上載入變慢 |

這一頁的主角是**真的貓咪照片**，插畫太搶眼會讓人分不清重點。
所以建議插畫只放在頁首當氛圍，下面讓照片說話。

如果還是想要整頁都有一點風格，可以加做「淡淡的重複花紋」（見下面 B），
透明度壓得很低，當作底紋。

---

### A. 頁首橫幅（建議先做這個）

**要做兩張**：電腦版是寬的，手機版是比較方的，一張圖沒辦法兩邊都好看。

上傳《認養流程_設計稿_v3.jpg》當風格參考，貼上第一節的風格描述，再加：

**電腦版**

```
【這張圖要畫什麼】
網站「等家的貓咪」頁面最上方的橫幅插畫。

【畫面內容】
- 一群可愛的貓咪，有的趴著、有的坐著、有的好奇地探頭，
  像是在溫暖的家裡等待有人來認識牠們
- 貓咪大約 5 到 7 隻，大小不一，姿勢與表情各不相同
- 橘白貓與灰白虎斑貓為主，也可以有一隻黑貓、一隻白貓、一隻三花貓
- 可以有柔軟的坐墊、毛線球、紙箱、小窗戶等溫馨小物
- 點綴少量的愛心、小閃光、貓掌印

【版面｜很重要】
- 寬高比 4:1 的橫幅，尺寸 1920 x 480
- 畫面「左半邊」要留白（只有淡藍白底色和極少的小裝飾），
  因為網頁會把標題文字放在那裡
- 貓咪集中在「右半邊」與「下緣」
- 上下左右的邊緣要自然淡出到底色 #F5F8FD，不要有明顯的邊框或色塊邊界
```

**手機版**

```
【這張圖要畫什麼】
同一個主題，手機版的頁首插畫。

【畫面內容】
- 跟電腦版同一批貓咪的感覺，但只放 3 到 4 隻，畫大一點
- 其他內容與電腦版相同

【版面｜很重要】
- 寬高比 3:2，尺寸 1080 x 720
- 畫面「上半部」留白，網頁會把標題文字放在那裡
- 貓咪集中在「下半部」
- 邊緣自然淡出到底色 #F5F8FD
```

---

### B. 淡淡的重複花紋（選做）

```
【這張圖要畫什麼】
可以無縫重複拼接的底紋圖案，當作網頁背景。

【畫面內容】
- 稀疏散落的小元素：小貓臉、貓掌印、愛心、小魚、小閃光、毛線球
- 元素都很小，彼此間隔很寬，大部分面積是空白底色
- 顏色要非常淡，像淡淡的浮水印（用風格描述裡的顏色，但降低飽和度、調淺）

【版面｜很重要】
- 正方形 1024 x 1024
- 必須是「無縫拼接」（seamless tileable pattern）：
  右邊緣要能接上左邊緣、下邊緣要能接上上邊緣，拼起來看不出接縫
- 底色是 #F6F9FD
- 元素不能碰到或被切在圖片邊緣以外的地方——
  如果要跨邊，另一側必須剛好接上
```

> 重複花紋的「無縫」AI 不一定做得好，拿到後我會先拼成 3×3 檢查接縫。

## 四、拿到圖之後

- [ ] 風格跟領養流程那幾張像不像？（輪廓線是咖啡色嗎？有腮紅嗎？）
- [ ] 圖上有沒有不小心出現文字或亂碼字母？
- [ ] 留白的位置對不對？（電腦版左半、手機版上半）
- [ ] 邊緣有沒有自然淡出，還是有一條明顯的邊？
- [ ] 貓咪有沒有畫壞（多一隻腳、眼睛歪掉、身體黏在一起）？

圖給 Claude，會處理：壓縮尺寸、調整邊緣與網站底色接合、
電腦版與手機版自動切換、放上網站。

## 五、之後其他頁面也照這個做

這份風格描述也可以用在：
- 首頁主視覺
- 「找到家的貓」頁首
- 「養貓小知識」的文章插圖
- 「支持我們」頁首
- 404 找不到頁面

每次只要換第三節的「畫面內容」和「版面」，**第一節的風格描述一個字都不要改**，
整個網站的插圖就會是同一個風格。

## 六、單隻貓介紹頁：依毛色換背景（2026-10-13）

點進某一隻貓時，背景會依牠的毛色變成不同場景。
網頁已經做好自動切換，目前先用漸層色頂著，**插畫做好丟給 Claude 就會換上去**。

### 七種主題

| 毛色 | 主題 | 想表達的感覺 |
|---|---|---|
| 黑貓 | 夜晚 | 星空、彎月、夜裡的屋頂與窗口暖光 |
| 白貓 | 雪地 | 雪花、雪人、覆雪的小屋 |
| 賓士貓 | 鋼琴 | 黑白琴鍵、音符（像穿燕尾服的紳士） |
| 三花貓 | 花園 | 白、橘、黑三色的花朵，春天 |
| 玳瑁貓 | 秋天 | 紅褐色的楓葉、落葉、橡實（玳瑁的顏色就像秋天） |
| 橘貓 | 夕陽 | 黃昏的天空、橘子、暖暖的陽光 |
| 虎斑貓 | 森林 | 綠色樹林、草地、蘑菇、小動物 |

### 網頁上背景實際露出來的位置（畫之前一定要知道）

```
手機（直式）                     電腦（橫式）
┌──────────────┐          ┌────┬──────────┬────┐
│  ★ 主場景區   │          │    │  主場景區  │    │
│  （上方約20%）│          │ 左 ├──────────┤ 右 │
├─┬──────────┬─┤          │ 側 │          │ 側 │
│ │          │ │          │ 裝 │ 白色資料卡 │ 裝 │
│ │ 白色資料卡│ │          │ 飾 │  （蓋住）  │ 飾 │
│ │ （蓋住）  │ │          │ 區 │          │ 區 │
│ │          │ │          │    │          │    │
└─┴──────────┴─┘          └────┴──────────┴────┘
```

- **手機**：中間幾乎整片被白色資料卡蓋住，只露出**上方一段**和**左右兩條很細的邊**。
  所以**主角（月亮、雪人、鋼琴…）要畫在最上面**。
- **電腦**：中間被資料卡蓋住，**左右兩側和上方**會露出來。
- 中間被蓋住的地方還是會透一點點出來（卡片是半透明的），
  所以中間要**畫得淡、畫得空**，不要放重點。

### 每個主題要做兩張

| | 尺寸 | 重點放哪 |
|---|---|---|
| 手機版 | 1080 × 1920（直式 9:16） | 上方 20% 放主場景；左右邊緣放小裝飾；中間淡、空 |
| 電腦版 | 1920 × 1080（橫式 16:9） | 左右各三分之一放裝飾與小貓；上方放主場景；中間淡、空 |

> 建議先做**黑貓（夜晚）和白貓（雪地）**兩個試試看——
> 一個最暗、一個最亮，這兩個沒問題的話，其他五個照著做就好。

### 提示詞範本

上傳《認養流程_設計稿_v3.jpg》當風格參考，貼上**第一節的風格描述**，再加這段。
`【】` 的地方照下面的表格換掉：

```
【這張圖要畫什麼】
網站上某一隻貓的介紹頁背景，主題是【主題】。

【畫面內容】
【場景描述】
可以放 1～2 隻小小的可愛貓咪在角落當點綴（照風格描述的畫法），
但不要畫成主角，主角是場景本身。

【版面｜很重要】
- 尺寸【尺寸】
- 【版面說明】
- 畫面中央的大片區域要畫得很淡、很空，因為網頁會在上面蓋一張白色的資料卡
- 整體不要太複雜，元素之間要有留白，看起來輕鬆活潑、不擁擠
- 不要有任何文字
```

**手機版的【版面說明】**：
`直式。主場景（最重要的東西）集中在畫面最上方約 20% 的範圍。左右兩側邊緣可以有細細的小裝飾往下延伸。中間與下半部要非常淡、留白。`

**電腦版的【版面說明】**：
`橫式。裝飾與小貓集中在畫面左右兩側各約三分之一的範圍，畫面上方可以有主場景（例如天空、月亮）。中間約三分之一的寬度要非常淡、留白。`

### 七個主題的【場景描述】

| 主題 | 【場景描述】 |
|---|---|
| 夜晚（黑貓） | 寧靜溫柔的夜晚：深藍色的夜空、彎彎的月亮、閃爍的小星星、遠處屋頂上的窗戶透出暖黃色燈光、幾隻螢火蟲。整體是溫暖可愛的夜晚，**不要恐怖、不要陰森**。底色是深藍色 #1F2B4D 到 #3D4A7A 的漸層。 |
| 雪地（白貓） | 下雪的冬天：飄落的雪花、圓滾滾的雪人、屋頂覆雪的小木屋、掛著小燈的松樹。底色是很淡的藍白色 #EEF5FC 到純白。 |
| 鋼琴（賓士貓） | 優雅的音樂會：黑白相間的鋼琴琴鍵沿著畫面邊緣延伸、飄浮的音符、小領結、小禮帽。底色是淡灰白色 #ECEEF2 到 #F6F7F9。 |
| 花園（三花貓） | 春天的花園：白色、橘色、深褐色三種顏色的小花（對應三花貓的毛色）、嫩綠的葉子、小蝴蝶。底色是淡粉杏色 #FFF4EE。 |
| 秋天（玳瑁貓） | 溫暖的秋天：紅褐色、橘色、深咖啡色的楓葉和落葉（對應玳瑁貓的毛色）、橡實、小蘑菇。底色是淡奶茶色 #F8ECDD。 |
| 夕陽（橘貓） | 暖暖的黃昏：橘色的夕陽、柔和的雲朵、幾顆圓滾滾的橘子、溫暖的光線。底色是淡橘色 #FFF3E2 到 #FFD8AE 的漸層。 |
| 森林（虎斑貓） | 綠意的小森林：圓圓的樹、草地、小蘑菇、小鳥、蝴蝶。底色是淡綠色 #EEF6EA 到 #D5E8CB。 |

### 圖拿到之後

給 Claude，會處理：壓縮、手機版與電腦版自動切換、確認資料卡上的字還讀得清楚。
如果插畫太花、字被干擾，會調整資料卡的透明度。
