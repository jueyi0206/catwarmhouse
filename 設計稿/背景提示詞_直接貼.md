# 毛色背景提示詞（直接複製貼上用）

> 給 Gemini 用。總共 7 個主題 × 2 張（手機版、電腦版）= 14 張。
> 建議先做**白貓（雪地）**和**黑貓（夜晚）**，一亮一暗，這兩個成功了再做其他五個。
> 2026-10-13 建立。完整說明見《網站插畫風格指南.md》第六節。

---

## 使用步驟

1. 在 Gemini 開一個**新對話**
2. **上傳《認養流程_設計稿_v3.jpg》**，然後貼「第一步」那一整段 → 送出
3. Gemini 回答之後，貼你要的那張圖的提示詞（第二步裡挑一段）→ 送出
4. 要下一張，**在同一個對話裡**直接貼下一段就好，風格不用重貼

> 如果 Gemini 畫到後面風格開始跑掉，就開新對話，從第 1 步重來。

## 第一步：先貼這段（每個新對話只要貼一次）

```
請仔細看我上傳的這張圖，接下來我會請你畫幾張網站的背景插畫，
每一張都必須完全沿用這張圖的美術風格：

【美術風格】
- 日系可愛風的手繪貓咪插畫，Q版比例：頭大、身體小、圓滾滾
- 輪廓線是深咖啡色（#4A1D0C），不是黑色；線條粗細一致、圓潤、
  帶一點手繪的不完美感
- 貓咪眼睛又大又圓，深色眼珠上有白色反光點
- 臉頰有粉嫩的橢圓腮紅（#FCBAB0），嘴巴是小小的「ω」形，耳朵內側淡粉色
- 上色是平塗色塊，幾乎沒有陰影；不要寫實、不要 3D、不要水彩暈染、不要厚塗
- 點綴的小裝飾：粉紅愛心（#F47479）、黃色短線與小閃光（#FDC06B）、
  藍灰色的貓掌印（#8896B6）
- 整體柔和、明亮、溫暖，像繪本插畫；元素之間有留白，不擁擠

【所有背景都要遵守的規則】
- 不要任何文字、字母、數字、標誌
- 不要出現人物
- 畫面「中央」要畫得很淡、很空，因為網頁會在中間蓋一張白色的資料卡，
  重點只放在上方和左右兩側
- 可以放 1～2 隻小小的貓咪在角落當點綴，但主角是場景，不是貓

看懂的話回答「了解」就好，先不用畫。
```

# 「等家的貓咪」頁首橫幅（群貓圖）

> 這一頁的最上方要放一條橫幅插畫，底下是篩選鈕和貓咪照片卡片。
> **點毛色篩選時，橫幅會換成該毛色的場景**（用現有的七張背景裁出來的）；
> 點「全部」時顯示的就是這張群貓圖，所以它是這一頁的門面。
> 一樣要做手機版和電腦版兩張。

## 用法

跟前面一樣：新對話、上傳《認養流程_設計稿_v3.jpg》、先貼本文件最前面的
「第一步」風格描述，再貼下面的其中一段。

## 手機版

```
請畫：網站「等家的貓咪」頁面最上方的橫幅插畫。

【畫面內容】
一群可愛的貓咪聚在溫暖的家裡，等待有人來認識牠們。
- 大約 5 到 6 隻貓，大小不一、姿勢和表情都不一樣：
  有的趴著打盹、有的坐著看向前方、有的從箱子裡探頭、有的翻肚
- 毛色要有變化，盡量涵蓋這幾種：橘白貓、灰白虎斑、黑貓、白貓、
  三花貓、黑白賓士貓（這是網站上的分類，每一種都出現一隻最好）
- 可以放柔軟的坐墊、紙箱、毛線球、貓抓板、小窗戶等溫馨的小物
- 點綴少量的愛心、小閃光、貓掌印

【氣氛】
溫暖、安心、有點期待的感覺，像在家裡等家人回來。
不要可憐兮兮、不要籠子、不要看起來像收容所。

【版面｜很重要】
- 橫式長條，寬高比 5:2（例如 1500 x 600）
- 畫面「左半邊」要大量留白，只有淡淡的底色和極少的小裝飾，
  因為網頁會把「等家的貓咪」這幾個字放在那裡
- 貓咪和小物集中在「右半邊」與「下緣」
- 上下左右的邊緣要自然淡出到底色 #F6F9FD，不要有明顯的邊框或色塊邊界
- 底色是很淡的藍白色 #F6F9FD 到 #EAF1FB
```

## 電腦版

```
同樣是「等家的貓咪」頁首橫幅，這次請畫電腦版。
畫面內容和氣氛跟剛才一樣，但：

【版面】
- 更寬的橫式長條，寬高比 4:1（例如 2000 x 500）
- 貓咪分散在「左右兩側」，中間留出一段空白給標題文字
- 可以多放一兩隻貓，因為畫面變寬了
- 邊緣一樣自然淡出到底色 #F6F9FD
```
