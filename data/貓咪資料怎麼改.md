# 貓咪資料怎麼改

> 全站的貓咪資料都在同一個檔：`cats.js`。
> 改這一個檔，七個頁面會自動更新。**不用碰任何 .html 檔。**

---

## 開檔案

用**記事本**或 **VS Code** 打開 `cats.js`。改完存檔，重新整理網頁就會看到。

⚠️ **不要用 Word 開**，Word 會把引號換成彎引號，網頁會壞掉。

---

## 一隻貓長這樣

```javascript
    {
      "id": "cream",
      "name": "奶油",
      "status": "wait",
      "sex": "公",
      "age": "年齡不詳",
      "color": "白色長毛",
      "colorType": "白貓",
      "feature": "耳朵往後捲、頭頂一小撮灰毛",
      "personality": "個性溫潤、親人，被摸會瞇眼、尾巴豎直",
      "fit": "待貓窩確認",
      "health": "已結紮；疫苗等醫療資訊以貓窩公告為準",
      "story": "待貓窩提供",
      "photos": ["cats/cream-1.jpg", "cats/cream-2.jpg"],
      "video": "",
      "confirmed": "2026-10-11"
    },
```

### 每個欄位是什麼

| 欄位 | 意思 | 注意 |
|---|---|---|
| `id` | 網址用的代號 | **用英文小寫，不能重複**，取好就不要改（改了舊連結會失效） |
| `name` | 貓咪名字 | 中文沒問題 |
| `status` | 狀態 | 只能填四個值，見下面 |
| `sex` | 性別 | 公／母 |
| `age` | 年齡 | 不確定就寫「年齡不詳」，會自動不顯示 |
| `color` | 花色 | 自由描述，例：橘虎斑、稀釋三花、白色長毛 |
| `colorType` | **毛色分類** | 「等家的貓咪」頁的篩選用，**只能填下面六個之一** |
| `feature` | 外觀特徵 | 例：耳朵往後捲 |
| `personality` | 個性一句話 | **卡片上會顯示這句，寫得生動一點** |
| `fit` | 適合什麼樣的家 | 例：適合獨貓家庭 |
| `health` | 健康狀況 | **最重要的欄位，一定要正確**。結紮、疫苗、驅蟲、特殊狀況 |
| `story` | 牠的故事 | 可以空白。**寫過去的遭遇要尊重、簡短，不批評原飼主** |
| `photos` | 照片清單 | 例：`["cats/cream-1.jpg", "cats/cream-2.jpg"]`。**列表頁只用第一張**，點進去會看到全部。空的 `[]` 會顯示貓咪圖示 |
| `video` | YouTube 網址 | 貼上就會在那隻貓的介紹頁出現影片，**留空白就不顯示** |
| `videoCover` | 影片封面（可省略） | 預設用影片在 YouTube 上的縮圖。想換成別張圖才填，例如 `"cats/sher-1.jpg"` |
| `confirmed` | 資料確認狀況 | 給內部看的備註，會在單隻貓頁面顯示紅框提醒。**正式上線前要清空** |

### colorType 要填分類清單裡的字

目前有七類，寫在 `cats.js` 最上面的 `_毛色分類`：

```
黑貓　白貓　賓士貓　三花貓　玳瑁貓　橘貓　虎斑貓
```

乳牛貓歸在賓士貓，不另外分一類。
不屬於任何一類的貓就留空白 `""` —— 牠還是會出現在「全部」裡面，
只是不會被任何一個篩選鈕選到。

### 要新增或細分分類

改 `cats.js` 最上面的 `_毛色分類` 那一行就好，**篩選鈕會自動跟著變**。
例如想加「灰貓」：

```javascript
"_毛色分類": ["黑貓", "白貓", "賓士貓", "三花貓", "玳瑁貓", "橘貓", "虎斑貓", "灰貓"],
```

然後把對應的貓的 `colorType` 填成 `"灰貓"` 就完成了。

**兩個要注意的地方：**

1. **沒有貓的分類，按鈕不會出現。** 這是故意的 —— 免得訪客點進去是空的。
   所以新增分類後要至少有一隻貓填了它，按鈕才會長出來。
2. **字要一模一樣。** 填「玳瑁」而清單裡是「玳瑁貓」，就會對不上。
   打錯的話，在瀏覽器按 `F12` 開 Console 會看到紅字提醒，告訴你哪一隻貓填錯。

### status 只能填這兩個

| 填什麼 | 用在哪 |
|---|---|
| `wait` | 等家中 → 出現在「等家的貓咪」頁 |
| `home` | 已找到家 → 出現在「找到家的貓」頁 |

**網頁上不顯示狀態標籤**，因為等家的貓咪一律都是等家中，標出來沒有意義。
卡片上的標籤顯示的是毛色分類。

## 新增一隻貓

1. 找到 `"cats": [` 這一行
2. 複製現有的一整段（從 `{` 到 `},`）
3. 貼在下面，改成新貓的資料
4. **檢查 `id` 沒有跟別人重複**
5. 存檔，重新整理網頁

⚠️ 注意逗號：每一段結尾都要有 `},`，**只有最後一隻貓是 `}`，沒有逗號**。

---

## 貓咪送養成功了，怎麼辦

這件事很重要——**已送養的貓要及時更新，不然還會有人來問**。

1. 把那隻貓的 `"status"` 從 `"wait"` 改成 `"home"`
2. 剪下牠那一整段
3. 貼到檔案最下面 `"adopted": []` 的中括號裡面
4. 存檔

這樣牠就會從「等家的貓咪」消失，出現在「找到家的貓」。

```javascript
  "adopted": [
    {
      "id": "cream",
      "name": "奶油",
      "status": "home",
      ...
    }
  ]
```

## 放影片

在 `video` 欄位貼上 YouTube 網址就好，下面幾種寫法都可以：

```
"video": "https://www.youtube.com/watch?v=XXXXXXXXXXX",
"video": "https://youtu.be/XXXXXXXXXXX",
"video": "https://www.youtube.com/shorts/XXXXXXXXXXX",
```

**Shorts（直式影片）會自動用直式的播放框**，不用另外設定。
網址裡有 `/shorts/` 就會偵測到，不然直式影片放在橫式框裡左右會是一片黑。

### 幾個設計上的說明

- **一隻貓建議只放一支**，最能代表牠個性的那支。放太多訪客不會全看。
- **搞笑的影片反而最好用** —— 能看出個性的影片，比任何文案都有說服力。
  判斷標準不是影片嚴不嚴肅，而是**主角是不是這隻貓**。
- **影片不會自動播放**。頁面只顯示一張封面圖和播放鈕，訪客點了才真的載入 YouTube。
  這樣手機開頁面才不會慢，訪客也不會還沒看就被 Google 追蹤。
- 封面會**優先用這隻貓的第一張照片**（`photos` 的第一個）。沒有照片時才改用 YouTube 的縮圖。
  所以建議照片和影片一起放，體驗最好。
- 貓咪送養後資料整段搬到 `adopted`，影片會跟著走，不用另外處理。

## 放照片

照片放在 `images\cats\`，檔名用「貓咪 id-第幾張」，例如 `cream-1.jpg`、`cream-2.jpg`。
然後在 `photos` 欄位列出來，**第一張就是列表頁的封面**，所以把最好看的放第一個。

### 張數不同，介紹頁的排法就不同

| 張數 | 排法 |
|---|---|
| 0 張 | 一個空相框，裡面放貓咪圖示 |
| 1 張 | 一張大的波浪相框，微微歪 |
| 2 張 | 左上一張、右下一張，交疊一點 |
| 3 張 | 左邊一張大的，右邊上下兩張小的（**建議張數**） |
| 4～5 張 | 上面照 3 張的排法，多的排在下面一列 |

最多放 5 張，再多畫面會太擠。

### 交給 Claude 處理比較保險

照片給 Claude 的話會自動處理這些，自己放要記得做：
- **轉正方向**（手機照片常常是橫躺的）
- **裁成正方形**，貓咪放在中間
- **縮小到 800 像素**（原檔 3～5 MB，手機會載很久）
- **清除照片裡的 GPS 位置資訊** ⚠️ 手機照片通常記錄了拍攝地點，
  不清掉的話等於公開貓窩地址
- 檢查有沒有拍到人、浮水印、其他貓

### 照片的規矩（貓窩規則，一定要遵守）

- **有人臉入鏡**（志工、領養人、送養會民眾）：**沒確認同意前一律不用**
- **不放醫療照**：傷口、手術、生病的照片都不放
- **不賣慘**：選貓咪狀態好、看起來舒服的照片；籠子裡的照片盡量少用
- **單貓照**：只拍到這一隻貓的照片，有其他貓入鏡的不用

### 照片大小

手機拍的照片動輒 5MB，直接放上網會讓手機開很慢。
建議先縮到**寬度 1000 像素以內**再放進去。可以用小畫家或線上工具縮。

## 改壞了怎麼辦

網頁變成空白，通常是這三個原因：

1. **逗號少了或多了** — 檢查每段結尾的 `},`
2. **引號變成彎引號** — 一定要用英文半形的 `"`，不能用「」或 "" 
3. **中括號弄不見了** — 檔案最後要有 `]` 和 `};`

檢查方法：在 Chrome 按 `F12` → 點「Console」分頁 → 紅色訊息會告訴你第幾行有問題。

**最保險的做法：改之前先複製一份備份。**
