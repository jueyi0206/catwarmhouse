# 貓咪資料怎麼改

> 全站的貓咪資料都在同一個檔：`cats.js`。
> 改這一個檔，七個頁面會自動更新。**不用碰任何 .html 檔。**

---

## 開檔案

用**記事本**或 **VS Code** 打開 `cats.js`。改完存檔，重新整理網頁就會看到。

⚠️ **不要用 Word 開**，Word 會把引號換成彎引號，網頁會壞掉。

---

## 一隻貓長這樣

```javascript
    {
      "id": "cream",
      "name": "奶油",
      "status": "wait",
      "sex": "公",
      "age": "年齡不詳",
      "color": "白色長毛",
      "feature": "耳朵往後捲、頭頂一小撮灰毛",
      "personality": "個性溫潤、親人，被摸會瞇眼、尾巴豎直",
      "fit": "待貓窩確認",
      "health": "已結紮；疫苗等醫療資訊以貓窩公告為準",
      "story": "待貓窩提供",
      "photo": "",
      "confirmed": "2026-10-11 瑞億確認待領養"
    },
```

### 每個欄位是什麼

| 欄位 | 意思 | 注意 |
|---|---|---|
| `id` | 網址用的代號 | **用英文小寫，不能重複**，取好就不要改（改了舊連結會失效） |
| `name` | 貓咪名字 | 中文沒問題 |
| `status` | 狀態 | 只能填四個值，見下面 |
| `sex` | 性別 | 公／母 |
| `age` | 年齡 | 不確定就寫「年齡不詳」，會自動不顯示 |
| `color` | 花色 | 例：橘虎斑、三花 |
| `feature` | 外觀特徵 | 例：耳朵往後捲 |
| `personality` | 個性一句話 | **卡片上會顯示這句，寫得生動一點** |
| `fit` | 適合什麼樣的家 | 例：適合獨貓家庭 |
| `health` | 健康狀況 | **最重要的欄位，一定要正確**。結紮、疫苗、驅蟲、特殊狀況 |
| `story` | 牠的故事 | 可以空白。**寫過去的遭遇要尊重、簡短，不批評原飼主** |
| `photo` | 照片檔名 | 例：`"cream.jpg"`。留空白會顯示貓咪圖示 |
| `video` | YouTube 網址 | 貼上就會在那隻貓的介紹頁出現影片，**留空白就不顯示** |
| `confirmed` | 資料確認狀況 | 給內部看的備註，會在單隻貓頁面顯示紅框提醒。**正式上線前要清空** |

### status 只能填這四個

| 填什麼 | 網頁顯示 | 什麼時候用 |
|---|---|---|
| `wait` | 等家中（綠色） | 正在送養 |
| `talking` | 洽談中（黃色） | 有人在談了，還沒確定 |
| `home` | 已找到家（紫色） | 已經送出去了 |
| `ask` | 資料待確認（紅色） | 資料還沒跟貓窩核對過。**正式上線前不應該還有這個** |

## 新增一隻貓

1. 找到 `"cats": [` 這一行
2. 複製現有的一整段（從 `{` 到 `},`）
3. 貼在下面，改成新貓的資料
4. **檢查 `id` 沒有跟別人重複**
5. 存檔，重新整理網頁

⚠️ 注意逗號：每一段結尾都要有 `},`，**只有最後一隻貓是 `}`，沒有逗號**。

---

## 貓咪送養成功了，怎麼辦

這件事很重要——**已送養的貓要及時更新，不然還會有人來問**。

1. 把那隻貓的 `"status"` 從 `"wait"` 改成 `"home"`
2. 剪下牠那一整段
3. 貼到檔案最下面 `"adopted": []` 的中括號裡面
4. 存檔

這樣牠就會從「等家的貓咪」消失，出現在「找到家的貓」。

```javascript
  "adopted": [
    {
      "id": "cream",
      "name": "奶油",
      "status": "home",
      ...
    }
  ]
```

## 放影片

在 `video` 欄位貼上 YouTube 網址就好，下面幾種寫法都可以：

```
"video": "https://www.youtube.com/watch?v=XXXXXXXXXXX",
"video": "https://youtu.be/XXXXXXXXXXX",
"video": "https://www.youtube.com/shorts/XXXXXXXXXXX",
```

**Shorts（直式影片）會自動用直式的播放框**，不用另外設定。
網址裡有 `/shorts/` 就會偵測到，不然直式影片放在橫式框裡左右會是一片黑。

### 幾個設計上的說明

- **一隻貓建議只放一支**，最能代表牠個性的那支。放太多訪客不會全看。
- **搞笑的影片反而最好用** —— 能看出個性的影片，比任何文案都有說服力。
  判斷標準不是影片嚴不嚴肅，而是**主角是不是這隻貓**。
- **影片不會自動播放**。頁面只顯示一張封面圖和播放鈕，訪客點了才真的載入 YouTube。
  這樣手機開頁面才不會慢，訪客也不會還沒看就被 Google 追蹤。
- 封面會**優先用這隻貓自己的照片**（`photo` 欄位）。沒有照片時才改用 YouTube 的縮圖。
  所以建議照片和影片一起放，體驗最好。
- 貓咪送養後資料整段搬到 `adopted`，影片會跟著走，不用另外處理。

## 放照片

1. 把照片放到 `images\` 資料夾
2. 在 `photo` 欄位填檔名，例如 `"photo": "cream.jpg"`

### 照片的規矩（貓窩規則，一定要遵守）

- **有人臉入鏡**（志工、領養人、送養會民眾）：**沒確認同意前一律不用**
- **不放醫療照**：傷口、手術、生病的照片都不放
- **不賣慘**：選貓咪狀態好、看起來舒服的照片

### 照片大小

手機拍的照片動輒 5MB，直接放上網會讓手機開很慢。
建議先縮到**寬度 1000 像素以內**再放進去。可以用小畫家或線上工具縮。

## 改壞了怎麼辦

網頁變成空白，通常是這三個原因：

1. **逗號少了或多了** — 檢查每段結尾的 `},`
2. **引號變成彎引號** — 一定要用英文半形的 `"`，不能用「」或 "" 
3. **中括號弄不見了** — 檔案最後要有 `]` 和 `};`

檢查方法：在 Chrome 按 `F12` → 點「Console」分頁 → 紅色訊息會告訴你第幾行有問題。

**最保險的做法：改之前先複製一份備份。**
